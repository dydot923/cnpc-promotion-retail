# 重点促销功能新手验收测试报告

## 1. 这份报告测什么

本报告只验收活动看板中甲方当前最关注的三部分：

1. **加油换购（统建）**
2. **非非促销（统建）**
3. **9.9 元商品专区**

测试依据是项目中的 [活动看板.xlsx](../data/活动看板.xlsx)：

- `加油换购（统建）`：源表 `A3:M22`
- `非非促销（统建）`：源表 `A3:L43`
- `参考2-9.9元商品专区`：源表 `A3:L197`

验收重点不是“页面上能看到活动名称”，而是：输入商品和业务条件后，点击 **一键计算促销**，系统确实返回对应的价格、赠品、赠券或组合包。

## 2. 测试前准备

### 2.1 启动程序

1. 确认 Docker Desktop 已启动。
2. 双击项目根目录的 `start-all.bat`。
3. 等待黑色窗口出现 `Start command finished.`。
4. 浏览器打开：<http://127.0.0.1:5174/operation-campaigns>

如果页面能打开，说明前端已经启动。也可以检查：

- 前端验收页：<http://127.0.0.1:5174/operation-campaigns>
- 收银页：<http://127.0.0.1:5174/checkout>
- 后端健康检查：<http://127.0.0.1:18083/actuator/health>

健康检查页面正常时，应看到类似 `{"status":"UP"}`。

### 2.2 进入验收入口

1. 在左侧菜单点击 **活动验收**。
2. 上方选择 **收银促销**。
3. 页面中间应看到三个重点标签：
   - `加油换购`
   - `非非促销`
   - `9.9元专区`
4. 页面顶部数量应大致显示：
   - 加油换购：`21 条`
   - 非非促销：`20 条`
   - 9.9 元专区：`194 个商品`

数量明显不对时，先不要继续验收，记录截图并联系开发人员。

## 3. 通用操作方法

### 3.1 商品录入

1. 进入收银页：<http://127.0.0.1:5174/checkout>。
2. 在“扫描条码，或输入商品名称、商品编码”输入框中输入商品编码或名称。
3. 点击 **查询并加入**。
4. 如果出现多个结果，向下滚动查看全部结果，点击正确商品。
5. 在购物车中确认商品名称、编码、单价和数量。

### 3.2 计算促销

1. 确认购物车已经有商品，或已经填写油品金额。
2. 点击页面上方的 **一键计算促销**。
3. 查看“推荐方案”：
   - 活动名称是否正确；
   - 应付金额是否正确；
   - 是否显示赠品或赠券；
   - 解释文字是否说明了命中的条件。
4. 不要只看“可用促销方案”列表。必须确认“推荐方案”或选中的方案中确实出现了优惠结果。

### 3.3 查看详细业务条件

收银页中有一个可展开区域 **验收日期、站点、充值与优惠券**。遇到日期、会员、站点相关活动时，展开它并检查：

- 站点编码：`1-A6501-C001-S001`
- 站点类型：普通加油站或加气站
- 省份：新疆
- 业务日期和时间
- 是否勾选会员
- 油品类型和油品金额

## 4. 加油换购验收

### 4.1 组合包验收

1. 在活动验收页进入 **加油换购**。
2. 点击 **打开完整换购清单**。
3. 油品类型选择 `汽油`，油品金额输入 `500`。
4. 页面应出现可换购的组合包和单品换购清单。
5. 找到 **加油换购组合包-驾驶包**，点击 **加入组合**。
6. 检查购物车是否自动加入：
   - 红牛 3 罐；
   - 0℃玻璃水 2 瓶；
   - 抽纸 1 包。
7. 点击 **一键计算促销**。

预期结果：

- 显示驾驶包组合换购活动；
- 组合价为 `25 元`；
- 购物车出现组合包中的全部商品；
- 如果库存不足，页面必须明确指出具体缺货商品，而不是报错或无提示。

### 4.2 单品换购验收

按下表逐项测试。每次测试前点击“新订单”清空上一次购物车。

| 油品条件 | 商品和数量 | 看板应显示的结果 |
|---|---|---|
| 汽油满 180 元 | 小水 4 瓶 | 2 元换购 4 瓶 |
| 汽油满 180 元 | 大水 4 瓶 | 4 元换购 4 瓶 |
| 汽油满 180 元 | 红牛 3 罐 | 12 元换购 3 罐 |
| 柴油满 300 元 | 小水 4 瓶 | 2 元换购 4 瓶 |
| 柴油满 300 元 | 大水 4 瓶 | 4 元换购 4 瓶 |
| 汽油满 180 元 | 优斯麦尔果汁 1L 1 瓶 | 9.9 元换购 1 瓶 |
| 汽油满 180 元 | 优斯麦尔果汁 0.3L 2 瓶 | 9.9 元换购 2 瓶 |
| 汽油满 180 元 | 优斯麦尔果汁 248ml 3 瓶 | 9.9 元换购 3 瓶 |
| 汽油满 180 元 | 优斯麦尔纯牛奶 250G 12 盒 | 39.9 元换购 1 箱 |

验收时重点检查“数量”是否正确。例如红牛必须是 3 罐，不能只加入 1 罐；牛奶整箱必须按 12 盒判断。

### 4.3 门槛反向测试

反向测试用于确认系统没有“未满金额也给优惠”的问题：

1. 只加红牛 3 罐，油品金额输入 `179` 元，点击计算。
2. 预期：红牛换购活动不可用，并显示“油品金额未满 180 元”或类似原因。
3. 把油品金额改为 `180` 元，再计算。
4. 预期：红牛 12 元换购活动变为可用。

## 5. 非非促销验收

### 5.1 香烟满额赠品，这是最重要的一组

活动验收页下方有“常用实操场景”。按以下顺序测试：

1. 点击 **香烟满555赠伊力特250**。
2. 收银页自动载入示例后，点击 **一键计算促销**。
3. 查看推荐方案中的“赠品/赠券权益”。

预期必须出现：

`优斯麦尔46度伊力特佳藏250ML x 1`

继续测试：

- **香烟满200二选一**：应出现 2 个可选赠品方案，其中一个是自有牛奶，另一个是果汁；
- **香烟满888赠伊力特500**：应出现 500ML 伊力特赠品。

如果香烟满 555 元没有显示 250ML 伊力特，这是不通过，不要用“有其他促销”代替判断。

### 5.2 便利店和棉包膜活动

1. 点击 **便利店满额赠品**，计算后确认出现可选赠品。
2. 点击 **棉包膜9卷礼包**，计算后确认礼包中出现多个赠品。
3. 查看推荐方案，确认赠品名称和数量，不只看活动名称。

### 5.3 逢 7、逢 9 日期活动

展开“验收日期、站点、充值与优惠券”，手工设置日期：

- 逢 7 加气：设置为每月 `7`、`17` 或 `27` 日，并选择加气站；
- 逢 9 全品惠：设置为每月 `9`、`19` 或 `29` 日，并选择普通加油站。

加入普通便利店商品后点击计算。

预期结果：

- 普通商品出现 `9 折` 或 `90%` 折扣；
- 香烟和化肥不应被错误地纳入全场 9 折。

### 5.4 赛事和中秋活动

赛事活动测试：

1. 日期设置在 `2026-06-12` 至 `2026-08-09` 之间；
2. 时间设置为 `18:00` 至次日 `02:00`；
3. 加入啤酒、咖啡、瓜子、冰淇淋、膨化食品或肉制品；
4. 点击计算，确认出现 `8.8 折`。

中秋活动测试：

1. 日期设置为 `2026-09-01` 至 `2026-09-30`；
2. 加入月饼商品，商品金额达到 `226` 元；
3. 会员场景应出现满 226 元减 50 元并赠 2 张 10 元汽油券；
4. 非会员金额达到 `326` 元时，应出现减 66 元。

## 6. 9.9 元专区验收

### 6.1 全量展示和搜索

1. 活动验收页点击 **9.9元专区**。
2. 确认页面显示 `194 个商品`。
3. 在搜索框输入 `70553214`。
4. 预期只显示：**卷心小面包 70553214**。
5. 页面应显示 `2件 / 9.9元`，而不是“每件 9.9 元”。

### 6.2 按包装系数实际结算

1. 点击 **装载2件**。
2. 检查购物车数量必须是 `2`。
3. 点击 **一键计算促销**。

预期结果：

- 推荐方案名称为 `9.9元商品专区-卷心小面包`；
- 应付金额为 `9.90 元`；
- 解释文字包含 `满2件按9.90元/组结算`。

再做一个反向测试：手工把数量改为 `1` 再计算。预期 2 件装活动不可用，并说明数量不足。这是正确行为，不是故障。

### 6.3 分页检查

清空搜索框后检查分页：

- 第一页能看到商品；
- 可以点击下一页；
- 页面底部显示总数 `194 个商品`；
- 不应只显示前几项后就没有结果。

## 7. 通过标准

一次完整验收至少应满足：

- 三个重点标签都能打开；
- 加油换购组合包能自动加入全部组合商品；
- 油品门槛不满足时活动会明确不可用；
- 香烟满 555 元能显示伊力特佳藏 250ML 赠品；
- 9.9 元专区显示 194 个商品；
- 9.9 元商品按包装系数计算，而不是统一按单件 9.9 元；
- 模糊搜索结果可以翻页查看；
- “加油换购”可以切回“加油站”；
- 页面无 `Station not found`、500 错误或白屏。

建议每个通过项保存一张截图，截图中同时包含商品、条件、推荐方案和赠品/赠券结果，作为甲方验收记录。

## 8. 常见问题处理

### 浏览器提示 `ERR_CONNECTION_REFUSED`

1. 关闭旧的浏览器页面；
2. 确认 Docker Desktop 正在运行；
3. 重新双击 `start-all.bat`；
4. 等待窗口出现 `Frontend and checkout proxy are ready.`；
5. 再打开 `http://127.0.0.1:5174/operation-campaigns`。

### 出现 `Station not found`

展开业务信息，确认站点编码为：

`1-A6501-C001-S001`

站点类型选择普通加油站，省份选择新疆，然后重新计算。

### 活动显示“未满足”

先检查四件事：

1. 油品类型是否正确；
2. 油品金额是否达到门槛；
3. 商品数量是否达到包装数量；
4. 日期和时间是否在活动有效期内。

如果以上都正确但仍失败，记录商品编码、数量、油品金额、日期、页面提示和截图，再交给开发人员排查。

### 9.9 商品单价低于 9.9 元

系统不会为了“促销”把原本更便宜的商品涨价到 9.9 元。此时活动可能显示不可用，这是保护顾客最低价的正常行为。
