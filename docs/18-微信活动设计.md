# 微信渠道活动设计

## 1. 模块归属

微信摇一摇、新客/低频/流失客户序列券属于小程序营销链路。checkout 只核销已发放且当前序号可用的券。

## 2. 序列券模型

| 模型 | 字段 |
|---|---|
| SequentialCouponChain | chainId、memberId、campaignId、currentStep、status |
| SequentialCouponStep | chainId、stepNo、couponTemplateId、unlockCondition |
| CouponUnlockEvent | eventId、chainId、redeemedCouponId、nextCouponId、occurredAt |

## 3. 结算边界

- 当前系统已支持普通券核销。
- “核销第一张后派发第二张”应由券生命周期服务监听 checkout confirm 事件完成。
- 第三张起限昆仑 e 享卡支付，需要 checkout confirm 请求携带 paymentMethod，由券服务校验。
