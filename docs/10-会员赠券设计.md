# 会员赠券设计

## 1. 模块归属

新增会员、潜在会员化、RFM 挽回、生日礼包属于会员系统/营销系统主动派券，不属于 checkout 实时促销计算。

## 2. 触发事件

| 活动 | 触发事件 |
|---|---|
| 新增会员 | 首次开通昆仑 e 享卡 |
| 潜在会员化 | 已注册未办卡，常用省份新疆 |
| RFM 挽回 | 客群标签命中，15 天一次 |
| 生日礼包 | 生日月触发 |

## 3. 券进入结算

派发后生成 `coupon` 实例；checkout 通过 `COUPON_REDEEM` 判断状态、有效期、会员、门槛、适用范围和排除品类。

## 4. 审计

派券动作记录 sourceEventId、campaignVersion、operator 或 system actor，避免手工补券无法追溯。
