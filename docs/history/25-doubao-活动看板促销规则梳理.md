| 便利店折扣 | 9折、会员专属价、券核销 | 取最优优惠 |
| 满减/赠券 | 满额赠券、满减 | 按最高档位计算 |
| 换购 | 各组合换购 | 只能选择一个组合 |

### 9.3 优先级规则

1. **油品促销** > **便利店促销** > **券核销** > **会员价**
2. 同类型促销取最优价格
3. 赠券活动与其他促销可叠加
4. 积分活动与其他促销可叠加
