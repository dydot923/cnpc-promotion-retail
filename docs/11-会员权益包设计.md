# 会员权益包设计

## 1. 模块归属

十全十美权益包、LNG/CNG 权益礼包属于会员权益包销售与权益发放链路，不直接改变 checkout 商品价格。权益包中的券、换购券、权益商品在发放后进入券实例或权益实例，结算时由 `COUPON_REDEEM` 或换购规则核销。

## 2. 核心模型

| 模型 | 字段 |
|---|---|
| MembershipPackage | packageId、name、salePrice、channel、status、version |
| PackageBenefit | benefitId、packageId、benefitType、couponTemplateId、productCode、quantity、validityRule |
| PackagePurchase | purchaseId、memberId、packageId、paidAmount、purchasedAt、status |
| BenefitInstance | instanceId、purchaseId、memberId、benefitType、targetId、status、validFrom、validUntil |

## 3. 结算接口

- 权益包销售系统负责创建券实例或权益实例。
- checkout 只读取可用券实例，不判断权益包购买资格。
- 换购券可映射为 `EXCHANGE_PURCHASE` 或 `COUPON_REDEEM`，必须带来源 packageId。

## 4. 活动覆盖

- D4 十全十美礼包：归本模块。
- I 会员权益包：归本模块。
- LNG+CNG 子表：可作为权益包商品构成导入来源。

## 5. 治理要求

权益包版本变更不能覆盖已售权益；已售权益按购买时版本核销。
