# 充值赠券设计

## 1. 模块归属

逢10超级十惠、小额充值赠券属于充值系统触发的派券活动。充值是否达标、是否十惠日、会员等级加赠等判断在充值系统完成；checkout 只核销已发放券。

## 2. 规则模型

| 模型 | 字段 |
|---|---|
| RechargeCampaign | campaignId、thresholdAmount、memberLevelRule、provinceRule、daysOfMonth、status、version |
| RechargeGiftPack | packId、campaignId、couponTemplateId、quantity、validDays |
| RechargeEvent | eventId、memberId、amount、campaignId、issuedCouponIds、occurredAt |

## 3. 与 checkout 的关系

- 充值系统发放汽油券、便利店券、洗车券。
- checkout 通过券实例核销，不重新判断充值金额。
- 券模板必须带 `minSpendAmount`、适用油品/品类、有效期、排除品类。

## 4. 覆盖活动

- A6 逢10超级十惠。
- B3 小额充值。
