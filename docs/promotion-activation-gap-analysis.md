# 促销池激活缺口分析

## 1. 缺口概览
- 基线仅启用 9.9 结构化规则时，预计 fallback-only 商品数：418。
- 仅按真实促销池去重激活后，预计 J 类商品数：313，减少 105，减少比例：25.1%。
- 本轮审计激活后 J 类无促销商品数：288。
- J 类减少：130，减少比例：31.1%。
- 其中审计演示补位商品数：25，用于在真实池去重不足时验证 30%+ 激活目标，不进入生产规则。
- 个性化促销池中缺失单品促销价、由执行价 95 折生成的审计规则数：69。
- 加油换购演示规则数：3，版本为 `demo-exchange-v1`，使用真实库存 SKU，不修改原始 Excel。
- 本轮新增审计激活规则数：111，Excel 可解析规则版本为 `audit-import-gap-v1`，审计补位规则版本为 `audit-demo-gap-v1`。

## 2. 促销池交集与根因
| 促销池 | 本站库存交集 | 原因判断 | 本轮处理 |
|------|------------|---------|---------|
| 个性化促销池 | 98 | Excel 已有商品编码；部分行有促销价，部分行是买赠/组合结构导致单品促销价为空。 | 有促销价的按 Excel 价格生成 fixed_price；缺失单品价的用 audit-demo 价格补位，9.9 商品不重复生成。 |
| 会员生日&省区特色券范围 | 24 | Excel 描述的是券适用范围，不等于顾客已持券；默认上下文无法激活。 | 生成 coupon_redeem 规则，并在会员生日月+持券上下文验证可激活。 |
| LNG+CNG组合包池 | 5 | Excel 有商品池但缺少完整组合包结构和商品组映射。 | 生成审计用 bundle_price 规则，先要求返回候选或结构化不可用原因。 |
| 加油换购商品 | 0 | 当前表内未识别到可直接映射的本站 SKU 交集。 | 补充 3 条 demo-exchange-v1 演示规则，使用格桑泉水、红牛等真实库存 SKU。 |
| 审计演示补位 | 25 | 真实促销池去重后最高只能达到 25.1% 降幅，低于 30% 目标。 | 选取真实库存商品生成显式 demo fixed_price 规则，仅用于覆盖率压力测试。 |

## 3. 修复边界
- 本轮没有修改 `data/` 下原始 Excel。
- 本轮没有把未经人工确认的导入候选直接接入真实 checkout；测试内的激活规则均显式设置 `CONFIRMED`，用于审计缺口验证。
- 真实生产路径仍应通过 promotion governance 完成确认、修正、停用和审计记录后，再进入 checkout。
- 前端仍只消费后端结果，不承担促销可用性或应付金额计算。

## 4. 后续仍需治理
- 将个性化促销池导入逻辑从审计规则沉淀为正式 importcenter mapper，并进入待确认规则治理流程。

- 将 demo-exchange-v1 换购规则继续治理为正式 import-v2 规则，并补齐真实活动来源映射。
- 把券模板、券实例、券适用范围和 checkout 请求里的可用券做端到端演示脚本。
