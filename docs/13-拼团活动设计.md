# 拼团活动设计

## 1. 模块归属

拼团成团、角色识别、24 小时有效期、开团/参团次数限制属于小程序活动系统。checkout 只核销拼团成功后发放的券。

## 2. 核心模型

| 模型 | 字段 |
|---|---|
| GroupBuyTeam | teamId、leaderMemberId、targetSize、status、expiresAt |
| GroupBuyMember | teamId、memberId、role、joinedAt |
| GroupBuyReward | teamId、memberId、couponTemplateId、quantity、issuedAt |

## 3. 结算边界

券实例进入 `coupon` 后由 `COUPON_REDEEM` 核销；checkout 不判断成团资格。
