# Promotion Retail Frontend

Frontend implementation is intentionally deferred until the rule engine, checkout API, and Excel import contract are stable.

When started, this app should use:

- React 18
- TypeScript
- Vite
- Ant Design
- TanStack Query
- Zustand

Frontend rule: do not implement promotion eligibility, final payable amount, exclusion category, fuel threshold, or stacking logic in React. Display backend results only.
